# Ai Bijlibabu — Firebase Online Master Data
1. Read `FIREBASE_SETUP_HINDI.md`.
2. Fill `firebase-config.js` from your Firebase Web App config.
3. Create one Admin user in Firebase Authentication.
4. Replace `REPLACE_WITH_YOUR_ADMIN_UID` in `firestore.rules` with the Admin user's UID and publish rules.
5. Upload the website files to the root of GitHub Pages repository.
6. Never upload personal consumer data to this public dashboard database.
